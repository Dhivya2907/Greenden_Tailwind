Greenden Nursery 🌿

Greenden is a simple nursery website created using HTML and Tailwind CSS.

Pages
Home Page – Contains the introduction, best-selling plants, customer reviews, and newsletter.
Products Page – Displays different plants with their names and prices.
Contact Page – Provides contact details and a contact form.

Technologies Used
HTML
Tailwind CSS

Features
Responsive design
Plant product display
Hover effects
Navigation between pages
Simple and clean design

Project Structure
Greenden/

├── images/
└── dist/

How to Run
Open index.html in a web browser to view the website.
